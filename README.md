Design Patterns

Welcome to my personal workspace for learning Design Patterns! 👋 

I set up this repository to keep my hands-on practice organized. Instead of tossing everything into one messy file, I'm breaking down each pattern into its own isolated folder. It makes it much easier to review the code later and see exactly how things work under the hood.

Since my background includes system-level programming in C, I focus on writing clean, clear implementations that show exactly how these architectural concepts operate in practice.

## 📂 What's Inside

I'm organizing the patterns by their standard categories. Here is what I've tackled so far:

### 🏗 Structural Patterns
* **[Decorator](./structural/decorator)** — Dynamically adding new behaviors to an object at runtime without altering its core structure.
* **[Composite](./structural/composite)** — Composing objects into tree structures and treating individual objects and groups the exact same way.
